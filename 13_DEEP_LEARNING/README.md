# Deep Learning

This section covers the fundamentals, frameworks, architectures, and techniques used in deep learning.

## Structure

| Directory | Description |
|---|---|
| `fundamentals/` | Core deep learning concepts such as neural networks, backpropagation, loss functions, optimization, regularization, and normalization. |
| `pytorch/` | Deep learning development with PyTorch, including tensors, autograd, modules, data loading, and training workflows. |
| `keras/` | High-level deep learning development with Keras, including models, layers, training, callbacks, and preprocessing. |
| `cnns/` | Convolutional Neural Networks and their applications, particularly in computer vision. |
| `rnns/` | Recurrent Neural Networks and sequence modeling. |
| `transformers/` | Transformer architectures, attention mechanisms, and modern sequence modeling. |
| `transfer_learning/` | Using pretrained models for new tasks through feature extraction and fine-tuning. |

## Learning Path

1. Deep Learning Fundamentals
2. PyTorch
3. Keras
4. CNNs
5. RNNs
6. Transformers
7. Transfer Learning

## Goal

Build a strong understanding of deep learning concepts and gain practical experience implementing and training neural networks using modern frameworks.

The long-term goal is to apply these skills to computer vision, model optimization, and edge AI deployment.
