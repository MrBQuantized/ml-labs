# CLUSTERING

## Definition

Clustering is an unsupervised task of identifying similar instances and assigning them to *clusters*, (i.e., groups of similar instances)

## Goal:
Group similar instances together into clusters 

## Applications:
Used for a wide variety of applications, including:
- **Customer segmentation**: You can cluster your customers based on their purcahses, their activity on your website, and so on. This provides useful information needed in adapting productss and marketing camapaigns to each segment. E.g. Recommender systems

- **Data analysis**: In a dataset clusters of similar instances are first discovered for easy analysis of clusters.

- Anomaly detection (outlier detection): 
- Image segmentation
- Semisupervised learning
- dimensionality reduction

## Algorithms:
- KMeans Clustering
- DSCAN
- Hierarchical
