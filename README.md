# 🧠 Machine Learning

A comprehensive repository documenting my journey through Machine Learning—from mathematical foundations to classical machine learning and, eventually, deep learning.

The goal of this repository is not only to learn machine learning algorithms, but also to understand the theory behind them, implement them correctly, and build real-world projects.

---

## 🎯 Objectives

- Build a solid foundation in Machine Learning.
- Strengthen mathematical intuition behind ML algorithms.
- Master Scikit-Learn for classical machine learning.
- Learn TensorFlow/Keras for deep learning.
- Develop reproducible end-to-end machine learning projects.
- Document concepts, experiments, and best practices.

## 📚 Learning Path

### 1. Fundamentals

Introduction to machine learning concepts, terminology, workflows, feature engineering, and the bias-variance tradeoff.

---

### 2. Mathematics for Machine Learning

Covers the mathematical foundations required for machine learning.

Topics include:

- Linear Algebra
- Calculus
- Probability & Statistics

---

### 3. Scikit-Learn

Learning the complete classical machine learning workflow.

Topics include:

- Data preprocessing
- Feature selection
- Model selection
- Model evaluation
- Pipelines
- Cross-validation
- Hyperparameter tuning
- Model persistence

---

### 4. Regression

Supervised learning algorithms for predicting continuous values.

Examples:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Elastic Net

---

### 5. Classification

Supervised learning algorithms for predicting categorical outcomes.

Examples:

- Logistic Regression
- K-Nearest Neighbors
- Decision Trees
- Random Forest
- Support Vector Machines
- Naive Bayes

---

### 6. Clustering

Unsupervised learning techniques for discovering hidden patterns.

Examples:

- K-Means
- Hierarchical Clustering
- DBSCAN

---

### 7. Dimensionality Reduction

Techniques for reducing feature dimensions while preserving useful information.

Examples:

- Principal Component Analysis (PCA)
- t-SNE
- UMAP

---

### 8. Projects

End-to-end machine learning projects covering:

- Data preprocessing
- Exploratory Data Analysis
- Model training
- Evaluation
- Hyperparameter tuning
- Model deployment basics

---

### 9. TensorFlow / Keras

Deep learning concepts and implementation.

Topics include:

- Artificial Neural Networks
- Convolutional Neural Networks
- Recurrent Neural Networks
- Transfer Learning
