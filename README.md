# 🧠 Machine Learning

A comprehensive repository documenting my journey through Machine Learning—from mathematical foundations to classical machine learning and, eventually, deep learning and edge deployment.

The goal of this repository is not only to learn machine learning algorithms, but also to understand the theory behind them, implement them correctly, and build real-world projects.

---

## 🎯 Objectives

- Build a solid foundation in Machine Learning.
- Strengthen mathematical intuition behind ML algorithms.
- Master Scikit-Learn for classical machine learning.
- Learn both TensorFlow/Keras and PyTorch for deep learning.
- Understand ensemble methods, time series, and imbalanced learning as first-class topics, not afterthoughts.
- Build model interpretability into the workflow, not bolt it on at the end.
- Develop reproducible end-to-end machine learning projects.
- Bridge classical/deep learning work toward Edge AI deployment (export, quantization, inference on constrained hardware).
- Document concepts, experiments, and best practices.

## 📚 Learning Path

### 1. Fundamentals
Introduction to machine learning concepts, terminology, workflows, feature engineering, and the bias-variance tradeoff.

### 2. Mathematics for Machine Learning
Linear Algebra, Calculus, Probability & Statistics — kept as separate subfolders since each has distinct notation and use cases in ML.

### 3. Scikit-Learn
The complete classical machine learning workflow: preprocessing, feature selection, model selection, evaluation, pipelines, cross-validation, hyperparameter tuning, model persistence.

### 4. Regression
Linear Regression, Ridge Regression, Lasso Regression, Elastic Net.

### 5. Classification
Logistic Regression, K-Nearest Neighbors, Decision Trees, Random Forest, Support Vector Machines, Naive Bayes.

### 6. Clustering
K-Means, Hierarchical Clustering, DBSCAN.

### 7. Dimensionality Reduction
Principal Component Analysis (PCA), t-SNE, UMAP.

### 8. Ensemble Methods
Bagging vs. Boosting theory, XGBoost, LightGBM, CatBoost, stacking — distinct from single-model Random Forest coverage under Classification.

### 9. Time Series
Trend/seasonality decomposition, ARIMA/SARIMA, Prophet, and ML-based forecasting approaches.

### 10. Model Interpretability
Feature importance, SHAP, LIME, partial dependence plots — understanding *why* a model predicts what it predicts.

### 11. Imbalanced Learning
Class weighting, SMOTE and other resampling techniques, and evaluation metrics suited to imbalanced data (precision/recall/F1, PR-AUC) rather than plain accuracy.

### 12. Recommendation Systems
Collaborative filtering, content-based filtering, matrix factorization, hybrid systems.

### 13. Deep Learning
Explores deep learning concepts, neural network architectures, and modern fraeworks, with practical implementations using PyTorch and Keras. Topic include CNNs, RNNs, Transformers, and tranfer learning.

### 14. Edge AI Export
Exporting and optimizing models for edge/embedded deployment: ONNX export, TensorFlow Lite, quantization, pruning, benchmarking inference on constrained hardware — the direct bridge to the Edge AI Engineering track.

### 15. Projects
End-to-end machine learning projects covering data preprocessing, EDA, model training, evaluation, hyperparameter tuning, and model deployment basics.
